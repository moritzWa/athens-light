The best markdown editors for Mac in 2026, compared

Moritz Wallawitsch · November 13, 2026

My markdown files opened in VS Code. I wanted them to open in something lighter, where # Title turns into a title as I type. It had to be free.

I looked at the usual options. This post says what each one is, what it costs, and who it fits. I also built my own, Athens Light, and I say where it falls short. Prices, licenses and download sizes are from each project's site and GitHub page on November 13, 2026.

The short answer

  • You want to open a .md file and edit it as rich text, with nothing else: Athens Light. It is the simplest of the six and 3 MB.
  • You want the most polished editor and $15 is fine: Typora.
  • You like seeing the markdown source and want a native app: MarkEdit.
  • You keep a linked notes system: Obsidian.
  • You write papers with citations: Zettlr.
  • You want free rich-text editing with many features and can live with a 150 MB app: Mark Text.

Typora

Typora is the editor most people mean when they say "WYSIWYG markdown". It shows formatted text as you type and hides the syntax. It also has a file tree, an outline panel, math, Mermaid diagrams, themes, and export to PDF, Word and other formats.

It costs $14.99 once, with a 15-day trial, and a license covers up to three devices. It is not open source. If you write a lot and want the finished product, it is worth the money. I wanted free, so I kept looking.

MarkEdit

MarkEdit calls itself "just like TextEdit on Mac but dedicated to Markdown". It is a native app of about 4 MB. It is free, MIT licensed, and built on the CodeMirror 6 editor. It follows the GitHub flavor of markdown and adds no syntax of its own.

It is not WYSIWYG. You see the markdown source with syntax highlighting, so # Title stays as typed. Extensions can add a preview, hide the syntax, or edit tables visually. If you like source, MarkEdit is excellent. I wanted the opposite, so it was not what I was looking for.

Mark Text

Mark Text is free, MIT licensed, and edits markdown as rich text. It supports math, front matter and emoji. It is actively developed: version 0.23.0 came out on October 21, 2026.

It is an Electron app, and the Apple silicon download is 150 MB. Its macOS builds are also unsigned. When I opened it, macOS said "Apple could not verify MarkText is free of malware". The release notes tell you to run xattr -d com.apple.quarantine /Applications/MarkText.app once. That works, but it is not what I wanted from a simple editor.

Obsidian

Obsidian is free for every use, including work. It is not open source. Your notes are plain markdown files in a folder, which it calls a vault. Its Live Preview mode formats text as you type.

Obsidian is a notes system: links between notes, plugins, themes. Paid extras are Sync at $4 a month (billed yearly) and Publish at $8 a month. The installer is 222 MB. If you only want to edit one file, it is a lot of app. If you keep a web of notes, nothing here beats it.

Zettlr

Zettlr is free and GPL-3.0 licensed. It describes itself as a "publication workbench". It is built for academic writing: citations through reference managers such as Zotero, and export through Pandoc and LaTeX. It is an Electron app with a 193 MB installer. For a thesis it is a strong pick. For a quick edit it is more than needed.

Athens Light

Athens Light does one thing. You open a .md file and edit it as rich text. It saves to the same file as you type. Every file opens as a native macOS tab. Cmd+N makes a new file, and clicking the title renames it. There are no vaults, no sync and no toolbar.

It is 3.4 MB because it is a small Rust shell (Tauri) around the web view that macOS already has. The editor inside is Tiptap. It is MIT licensed and the code is on GitHub.

Where it falls short

  • Your first edit rewrites the whole file in the editor's markdown style. Bullet characters and spacing can change.
  • Files with raw HTML or footnotes open read-only, because the editor cannot write them back without losing them.
  • Front matter, images, task lists and tables survive. There is no file tree, no outline, no math, no diagrams and no export.
  • The app is for Apple silicon Macs. It is not notarized yet, so macOS asks you to confirm it once, like Mark Text. Building it from source avoids that.

Which one to pick

If you edit markdown files now and then, and want them to open as rich text in a small free app, use Athens Light. If you write all day, pay for Typora. If you prefer source, use MarkEdit. If your notes link to each other, use Obsidian. If you cite papers, use Zettlr. If you want a free rich-text editor with a long feature list, use Mark Text.

Athens Light is on GitHub. It takes about a minute to install, and the whole app is under 700 lines of code, so you can read all of it.
