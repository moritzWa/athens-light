The best markdown editors for Mac in 2026, compared

Moritz Wallawitsch · November 13, 2026 · Updated November 19, 2026

My markdown files opened in VS Code. I wanted them to open in something lighter, where # Title turns into a title as I type. It had to be free.

New to .md files? Start with what a .md file is and how to open one.

I looked at the usual options. This post says what each one is, what it costs, and who it fits. I also built my own, Athens Light, and I say where it falls short. I first wrote it on November 13 with six editors. On November 19, 2026 I added MacDown 3000, iA Writer, Bear and Ulysses and re-checked every price, license and download size against each project's site and GitHub page.

Eight of the ten screenshots show the same note, opened on a Mac in a window of the same size. Bear and Ulysses have none. They install only through the Mac App Store, and I did not sign my test Mac into an Apple ID.

The short answer

  • You want to open a .md file and edit it as rich text, with nothing else: Athens Light. It is the simplest of the ten and a 2.4 MB download.
  • You want the most polished editor and $15 is fine: Typora. It is not free. It has a 15-day trial.
  • You like seeing the markdown source and want a native app: MarkEdit.
  • You want the old MacDown, markdown on the left and a preview on the right: MacDown 3000. It is free and maintained. The original MacDown is not.
  • You keep a linked notes system: Obsidian.
  • You write papers with citations: Zettlr.
  • You want free rich-text editing with many features and can live with a 150 MB app: Mark Text.
  • You write a lot, want plain .md files on disk and will pay $49.99 once: iA Writer.
  • You want notes with tags that sync across your Apple devices: Bear. Its notes live in its own library, not as files.
  • You write long projects and will pay a subscription: Ulysses.

Typora

Typora is the editor most people mean when they say "WYSIWYG markdown". It shows formatted text as you type and hides the syntax. It also has a file tree, an outline panel, math, Mermaid diagrams, themes, and export to PDF, Word and other formats.

It costs $14.99 once, with a 15-day trial, and a license covers up to three devices. It is not open source. If you write a lot and want the finished product, it is worth the money. I wanted free, so I kept looking.

Is Typora free?

No. Typora gives you a 15-day free trial. After that you need a license. It costs $14.99 once, with no subscription, and covers up to three devices. Typora offers a refund within 30 days of buying. This is from store.typora.io and Typora's purchase page, checked on November 19, 2026.

Typora used to be free. It was a free beta until version 1.0 came out in November 2021 and added the paid license. The trial badge in the screenshot above reads "UNREGISTERED". If you do not want to pay, MarkEdit, MacDown 3000, Mark Text and Athens Light are free. Mark Text is the closest free match to how Typora edits.

MarkEdit

MarkEdit calls itself "just like TextEdit on Mac but dedicated to Markdown". It is a native app, and the Apple silicon download is 3.3 MB. It is free, MIT licensed, and built on the CodeMirror 6 editor. It follows the GitHub flavor of markdown and adds no syntax of its own.

It is not WYSIWYG. You see the markdown source with syntax highlighting, so # Title stays as typed. Extensions can add a preview, hide the syntax, or edit tables visually. If you like source, MarkEdit is excellent. I wanted the opposite, so it was not what I was looking for.

Mark Text

Mark Text is free, MIT licensed, and edits markdown as rich text. It supports math, front matter and emoji. It is actively developed: version 0.23.0 came out on October 21, 2026.

It is an Electron app, and the Apple silicon download is 150 MB. Its macOS builds are also unsigned. When I opened it, macOS said "Apple could not verify MarkText is free of malware". The release notes tell you to run xattr -d com.apple.quarantine /Applications/MarkText.app once. That works, but it is not what I wanted from a simple editor.

Obsidian

Obsidian is free for every use, including work. It is not open source. Your notes are plain markdown files in a folder, which it calls a vault. Its Live Preview mode formats text as you type.

Obsidian is a notes system: links between notes, plugins, themes. Paid extras are Sync at $4 a month (billed yearly) and Publish at $8 a month. The installer is 222 MB. If you only want to edit one file, it is a lot of app. If you keep a web of notes, nothing here beats it.

Zettlr

Zettlr is free and GPL-3.0 licensed. It describes itself as a "publication workbench". It is built for academic writing: citations through reference managers such as Zotero, and export through Pandoc and LaTeX. It is an Electron app with a 193 MB installer. For a thesis it is a strong pick. For a quick edit it is more than needed.

MacDown 3000

MacDown 3000 is a free, MIT licensed markdown editor for macOS. You type markdown on the left and the formatted note updates on the right. It is not WYSIWYG. It handles math, GitHub task lists, front matter, and export to HTML and PDF.

It is the maintained fork of MacDown, and that is the one to download if you searched for "macdown". The macdown.app site lists version 3000.0.8, released on November 2, 2026, with a 3000.0.9 release candidate after it. The download is 8.8 MB. It is a universal app for macOS 11 and later, and it is signed and notarized by Apple. You can also install it with brew install --cask macdown-3000.

The original MacDown stopped. Its last release, 0.7.3, is from January 2020, and its last commit is from April 2021. I opened the 0.7.3 download and it contains an Intel-only binary, so on an Apple silicon Mac it runs through Rosetta. Use MacDown 3000 instead.

MacDown and Mou

Mou came first. Chen Luo made it, and the MacDown site says he stopped active development. Tzu-ping Chung built MacDown as a free replacement, and MacDown's README says some of its themes come from Mou. MacDown 3000 continues that line. If you are looking for a Mou alternative, MacDown 3000 is the direct successor. I could not load Mou's own site when I checked, so I left Mou out of the table.

iA Writer

iA Writer is a paid, closed-source writing app. On the Mac it costs $49.99 once, either from the Mac App Store or directly from iA. There is a 7-day free trial, and iA says no credit card is needed. It runs on macOS 10.15 and later.

It edits plain .md files. When I opened my sample note from outside its library, iA Writer said "You're editing a document outside iA Writer Library" and let me keep editing it where it was. It shows the markdown source with light syntax highlighting. A Preview button shows the formatted version, and Focus Mode fades everything except the current sentence or paragraph. It exports to PDF, Word and HTML. It is not WYSIWYG.

Two things to know. The trial from iA's own download needs an email address and a confirmation code before it starts, and a newsletter box is ticked for you. And iA's pricing page says a one-time payment is not a lifetime license: minor updates are free, but major updates may cost money. The direct download is a 40.9 MB zip.

Bear

Bear is a notes app for Mac, iPhone and iPad. It is closed source. Its site says markdown formatting appears live as you type, and it organizes notes with tags. I did not install it, because it comes only from the Mac App Store.

The free version does not sync and exports to markdown, plain text, TextBundle and RTF. Bear Pro adds iCloud sync, more themes, and export to PDF, HTML, Word and ePub. It costs $2.99 a month or $29.99 a year, with a 7-day trial.

This matters if you want to open a .md file. Bear keeps notes in its own database, not as files you can see in Finder. To work on a .md file you import it with File, Import From, Markdown Folder, or Import Notes. Bear adds the text as a new note in its library. After that the note and the file are separate. Bear is a good notes app. It is not a way to edit a file in place.

Ulysses

Ulysses is a writing app for Mac, iPhone and iPad. It is closed source and subscription only: $39.99 a year or $5.99 a month in the US, with a free trial, from the Mac App Store or Setapp. The Mac Store listing asks for macOS 15.4 or later. I did not install it.

Ulysses keeps your writing in its own library, which syncs through iCloud. It uses its own markup, called Markdown XL. You can add a folder of .md files as an External Folder, and Ulysses will read and write them as markdown. Ulysses's help says some Ulysses features do not work on files stored that way. It is built for long projects with many sheets, not for opening one file.

Athens Light

Athens Light does one thing. You open a .md file and edit it as rich text. It saves to the same file as you type. Every file opens as a native macOS tab. Cmd+N makes a new file, and clicking the title renames it. There are no vaults, no sync and no toolbar.

Athens Light is the minimalist version of Athens, an AI writing editor I built earlier. Athens is a markdown-based WYSIWYG editor with AI suggestions, collaboration and Google Docs import. Athens Light keeps the editing and drops the rest.

The download is 2.4 MB, and the installed app is 4.7 MB. It is small because it is a small Rust shell (Tauri) around the web view that macOS already has. The editor inside is Tiptap. It is MIT licensed and the code is on GitHub.

Where it falls short

  • Your first edit rewrites the whole file in the editor's markdown style. Bullet characters and spacing can change.
  • Files with raw HTML or footnotes open read-only, because the editor cannot write them back without losing them.
  • Front matter, images, task lists and tables survive. There is no file tree, no outline, no math, no diagrams and no export.
  • The app is for Apple silicon Macs only. It is signed and notarized by Apple, so it opens without a warning.

Which one to pick

If you edit markdown files now and then, and want them to open as rich text in a small free app, use Athens Light. If you write all day and want rich text, pay for Typora. If you prefer source, use MarkEdit. If you want source with a preview beside it, use MacDown 3000. If your notes link to each other, use Obsidian. If you cite papers, use Zettlr. If you want a free rich-text editor with a long feature list, use Mark Text.

If you write all day and prefer source, iA Writer is the polished paid choice, and it keeps plain files. Bear and Ulysses are better as places to keep writing than as editors for the .md files you already have.

Athens Light is on GitHub. It takes about a minute to install, and the code is small enough to read.
