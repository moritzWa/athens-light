The best markdown viewers for Mac in 2026

Moritz Wallawitsch · November 19, 2026

A markdown viewer shows a .md file as formatted text. You read it. You do not write in it. On a Mac you have three kinds of choice: a preview in Finder, a small reader app, or an editor that also reads.

This page covers the ones I could verify. I built Athens Light, which is an editor that doubles as a viewer, so I am biased. I say where it falls short. Prices, sizes and licenses are from each app's own site, GitHub page or App Store page on November 19, 2026. I installed the free and trial ones on a Mac running macOS 26.5 and opened the same note in each.

New to .md files? Start with what a .md file is. If you want to write in them, see the comparison of markdown editors. If the files come from Claude Code or Codex, see how to read agent files on Mac.

The short answer

  • You want to press Space in Finder and see formatted text: QLMarkdown. It is free and open source.
  • You want a free app that opens a file and shows it with an outline: Markdown Preview. It is free, MIT licensed, and needs macOS 15.
  • You want free, open source, with tabs, math and diagrams: Markpad.
  • You write in another editor and want a live preview and PDF or Word export: Marked 3.
  • You read files that other people or a coding agent keep changing: Leaf marks the passages that changed. It costs $9.99 and needs macOS 26.
  • You want a paid reader with Quick Look, an outline and diagrams: MacMD Viewer, $19.99.
  • You want to read, and sometimes fix a typo, in a tiny app: Athens Light.
  • You already have VS Code, Obsidian or Typora: use them. They all render markdown.

How to preview .md files in Finder with Quick Look

Select a file in Finder and press Space. That is Quick Look. It shows a file without opening an app.

Quick Look does not render markdown. On my test Mac (macOS 26.5.2) it showed only a file card with the name, type and size. The same text saved as a .txt file showed as plain text. What you see can depend on which apps you have installed.

To get formatted text, add a Quick Look extension. Since macOS 15, an extension has to ship inside an app. The steps are the same for all of them:

  1. Install the app, for example QLMarkdown (brew install --cask qlmarkdown, or the download on its releases page).
  2. Open the app once. macOS only registers the extension after the first launch. A notification says that a Quick Look extension was added.
  3. Open System Settings, General, Login Items & Extensions, and find Quick Look. Check that the markdown extension is on.
  4. Press Space on a .md file.

Only one extension answers for a file type. My test Mac had four that claim .md: QLMarkdown, MarkEdit, Obsidian and MacDown 3000. I turned the other three off before this screenshot. If Space still shows the wrong thing, turn off the extensions you do not want.

Four options work this way. QLMarkdown is free. Marked QL costs $9.99. Markdown Preview and MacMD Viewer include a Quick Look extension with their apps.

QLMarkdown

QLMarkdown is a Quick Look extension and nothing else. Its own README says it is not meant to be a standalone viewer. It is free, GPL-3.0 licensed, and has 3,800 stars on GitHub. The latest release is 1.5.7 from October 2, 2026. The download is 26 MB, signed and notarized.

It follows GitHub's markdown rules and adds syntax highlighting, math, Mermaid diagrams, emoji and highlighted text. It does not open a window. If you want to read in an app, pick another row.

Markdown Preview

Markdown Preview is a native app for reading .md files. It is free and MIT licensed, with 2,900 stars on GitHub. The download is a 10 MB disk image, and it needs macOS 15 or later. You can also install it with brew install --cask markdown-preview.

It has an outline sidebar, search, themes, and a Quick Look extension. It also has an edit mode (Cmd+E) with a formatting toolbar, so it can fix a typo too. It is young: the version is 0.0.74, released on November 17, 2026. Releases come often. This is the one I would try first if you want a free reader app.

Markpad

Markpad calls itself "the Notepad equivalent for Markdown". It is free, BSD-3-Clause licensed, and has 1,400 stars. It is built with Tauri and runs on Mac, Windows and Linux. The disk image is 19 MB and works on Intel and Apple silicon Macs. The build I tested is signed and notarized.

It renders math (KaTeX) and Mermaid diagrams, has tabs, a table of contents, and reloads a file when it changes on disk. It also has a full code editor (Monaco) with a split view. It exports to HTML. Install it with brew install --cask markpad.

Marked 3

Marked is the long-standing preview app by Brett Terpstra. Its welcome screen says it is "an advanced Markdown preview application (not an editor)". You write in VS Code, Obsidian, Scrivener or anything else. Marked watches the file and redraws the preview each time you save.

It adds proofreading tools, themes, a table of contents, and export to PDF, HTML, DOCX and EPUB. It is the only app here built around publishing.

It is also the most expensive. Marked 3 costs $2.99 a month, $29.99 a year or $69.99 once. Those are introductory prices. The regular prices are $4.99, $49.99 and $89.99. Marked 2 is still sold for $14.99. The direct download is 90 MB. I did not get a screenshot, because the app asks you to pick a plan before it shows a document. The page says there is a free trial, and the app says 7 days.

Leaf

Leaf is a read-only markdown viewer for Mac, iPhone and iPad. Its one idea is change marks. It keeps the version of each file you last read. When someone edits the file, Leaf puts a bar next to every new or reworded passage and lets you tap to see the earlier wording. It suits a shared plan, meeting notes in an iCloud folder, or a PLAN.md that a coding agent keeps rewriting.

It costs $9.99 once after a 14-day trial. It is sold as a direct download (7.5 MB, notarized) and is not on the Mac App Store. The catch is the requirement: it needs macOS 26 or later.

MacMD Viewer

MacMD Viewer is a paid reader with a Quick Look extension. It costs $19.99 once for one Mac. It needs macOS 14 or later and the download is 5.4 MB. It has an outline sidebar, 12 themes, live reload, Mermaid diagrams and PDF export. It is also on Homebrew and Setapp.

There is no free trial, only a refund in the first 14 days. For that reason I did not install it and have no screenshot. Everything here is from its site.

Read.md

Read.md is a reader from the Mac App Store, and it also runs on iPhone and iPad. It is free. A paid unlock adds export to Word, PDF and HTML and browsing GitHub repositories. It has a table of contents, search and Mermaid diagrams. It has 121 ratings with a 5.0 average, and the last update was October 5, 2026. I did not test it.

Athens Light

Athens Light is a markdown editor, not a reader. It works as a viewer because it opens a .md file straight into formatted text and has nothing else on screen. The disk image is 2.6 MB. It is free and MIT licensed, and the code is on GitHub.

One feature matters for readers. If another program changes the file, Athens Light reloads it. I tested it: I opened a note, added a line to the file from the command line, and the new line appeared in the window within seconds, while the window was in the background. That helps if you read files that git or an agent rewrites.

Where it falls short as a viewer

  • It is an editor. It saves as you type, so a stray keystroke changes the file.
  • Your first edit rewrites the file in the editor's markdown style. Bullets and spacing can change.
  • Files with raw HTML or footnotes open read-only, because the editor cannot write them back without losing them.
  • It has no Quick Look extension, no outline, no Mermaid diagrams, no math and no export.
  • It is for Apple silicon Macs only.

Editors that also read

If you have one of these already, you may not need a separate viewer.

  • VS Code. Free. Press Shift+Cmd+V in a markdown file to see the preview, or Cmd+K then V to put it beside the text. It is a 394 MB download.
  • Obsidian. Free, not open source, 233 MB. It reads your .md files inside a folder it calls a vault. The app also ships a Quick Look extension.
  • Typora. $14.99 once with a 15-day trial, 15 MB. It shows formatted text and calls itself "a minimal Markdown editor and reader".
  • MarkEdit. Free, MIT, 3.4 MB. It shows the markdown source with highlighting. A separate extension adds a preview.

I compare these in the editor comparison.

What I left out

The Mac App Store has dozens of markdown viewers that appeared in 2026, most with no ratings yet. Several are named MD Viewer or MDViewer, so a name alone does not say which one you mean. I did not pick among them. I also left out MarkdownViewer (markdownviewer.app), because its site returned an error when I checked, and mdMD, because I could not verify anything about it beyond its App Store listing.

Which one to pick

If you only want to glance at a file, install QLMarkdown and press Space. If you want a free app to read in, use Markdown Preview. If you read files that keep changing and run macOS 26, try Leaf. If you publish from markdown, buy Marked. If you want to read and edit in the smallest app, use Athens Light.

Questions

Does a Mac have a built-in markdown viewer?

No. Quick Look shows a file card or plain text, depending on the Mac. TextEdit shows the raw symbols. You need an app or a Quick Look extension to see formatted text.

What is the best free markdown viewer for Mac?

For Finder, QLMarkdown. For an app, Markdown Preview or Markpad. All three are free and open source.

Can I view a markdown file without installing anything?

Yes, in a browser, with an online markdown previewer. You paste the text in. That sends your text to a website, so use an app for private files.

How do I make .md files open in the viewer I picked?

Select a .md file, press Cmd+I, choose the app under Open with, and click Change All.
