What is a .md file? How to open and edit one on Mac

Moritz Wallawitsch · November 19, 2026

A .md file is a plain text file written in Markdown. Markdown is a way to mark up text with ordinary characters: a # in front of a line makes it a heading, and **two stars** around a word make it bold. The file holds only text, so any text editor can open it.

If you double-clicked one on a Mac and got an error, or a wall of symbols, this page is for you.

What is inside a .md file

Here is a short one:

# Trip notes

Flights are **booked**. Still to do:

- [x] Hotel
- [ ] Rental car

See the [map](https://maps.apple.com).

Opened in a Markdown editor, that shows a large title, a line with one bold word, a checklist and a link. Opened in a plain text editor, you see exactly what is above. Both are the same file.

John Gruber created Markdown in 2004 so that people could write for the web without typing HTML. It stuck because the plain version is readable on its own.

Where .md files come from

  • Code projects. Almost every repository on GitHub has a README.md that explains the project.
  • AI tools. Coding agents such as Claude Code read and write files like CLAUDE.md, AGENTS.md and plan files. Many chat tools can export an answer as Markdown.
  • Notes apps. Obsidian and others keep every note as a .md file in a folder.
  • Docs and blogs. Many documentation sites and blogs are written in Markdown.

The file extension is sometimes .markdown instead. It is the same format.

Five ways to open a .md file on Mac

1. TextEdit, already on your Mac

Right-click the file, choose Open With, then TextEdit. You see the raw text with the symbols. It is fine for reading a short file and fixing a typo. It does not format anything.

2. Quick Look in Finder

Select the file and press Space. Quick Look shows the text without opening an app. It is a fast peek, and it also shows the raw symbols.

3. A code editor

If you already use Visual Studio Code or another code editor, it opens .md files and can show a formatted preview next to the text. It is a big app for reading one file.

4. A Markdown editor that shows formatted text

This is what most people want: open the file and see a title, bold words and a checklist, then click and type. Several apps do this. I compared six of them on price, size and how you edit.

5. Athens Light

I built Athens Light for exactly this case. It is free and open source, and the app is about 3 MB. Double-click a .md file and it opens as formatted text. Edit it, and the changes save back to the same file as you type. There is nothing to set up: no vault, no account, no sync.

Install it in Terminal:

curl -fsSL https://athens-light.app/install.sh | sh

Or download the disk image from GitHub and drag the app to Applications. It runs on Apple silicon Macs.

Make .md files open in the app you want

  1. Select any .md file in Finder and press Cmd+I.
  2. Under Open with, pick the app.
  3. Click Change All, then confirm.

From Terminal, open notes.md uses that default, and open -a "Athens Light" notes.md picks the app yourself.

Is it safe to edit a .md file?

Yes. It is plain text, so nothing runs when you open it. One thing to know: a Markdown editor that shows formatted text rewrites the file in its own style when you save. Bullet characters or spacing can change, and unusual syntax may not survive. For notes and docs this does not matter. If a file has to stay byte for byte the same, such as a config file, use a plain text editor.

Questions

Can I open a .md file in Word or Google Docs?

Word opens it as plain text. Google Docs can import Markdown and convert it to a document, but you lose the file format. If you want to keep the .md file, edit it in a Markdown editor.

Can I convert a .md file to PDF?

Yes. Most full-featured Markdown editors export to PDF. Athens Light does not export. It only edits.

Do I need to know Markdown to use one?

No. In an editor like Athens Light you can type normally. If you do want shortcuts, typing # at the start of a line makes a heading and - starts a list.
